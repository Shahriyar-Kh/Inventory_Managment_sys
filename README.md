# Inventory Management System (IMS)

![Python](https://img.shields.io/badge/Python-3.x-blue) ![SQLite](https://img.shields.io/badge/Database-SQLite-lightgrey) ![Tkinter](https://img.shields.io/badge/GUI-Tkinter-green) ![Pillow](https://img.shields.io/badge/Images-Pillow-yellow)

## 📌 Overview
The **Inventory Management System (IMS)** is a desktop application built using **Python (Tkinter)** for the interface and **SQLite** as the database.  
It is designed to help businesses efficiently manage their **employees, suppliers, categories, products, and sales**.

## 🚀 Features
- ✅ Employee Management  
- ✅ Supplier Management  
- ✅ Category Management  
- ✅ Product Management  
- ✅ Sales Management  
- ✅ Real-time Dashboard (Total Employees, Suppliers, Categories, Products, and Sales)  
- ✅ User-friendly GUI with Tkinter  
- ✅ Lightweight database with SQLite  

## 🛠️ Tech Stack
- **Programming Language**: Python 3.x  
- **GUI Framework**: Tkinter  
- **Database**: SQLite  
- **Image Handling**: Pillow (PIL)

## ⚡ Installation & Usage
### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Shahriyar-Kh/Inventory_Management_System.git
cd Inventory_Management_System
```

### 2️⃣ Create Virtual Environment (Optional but Recommended)
```bash
python -m venv ims_env
source ims_env/bin/activate   # On Linux/Mac
ims_env\Scripts\activate    # On Windows
```

### 3️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Application
```bash
python Dashboard.py
```
